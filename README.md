An enterprise-grade, microservices-based Smart Parking application. This system utilizes Edge Computer Vision for real-time spatial density analysis and Machine Learning for time-series availability forecasting. Built to replace expensive sensor networks with standard CCTV infrastructure.

---

## 🧠 System Architecture Overview

This project is intentionally decoupled into two primary microservices, separating the heavy video processing from the user interface and analytics engine:

### 1. The Edge Vision Node (`step3b_main.py`)
This backend script operates as an "Edge Device," processing heavy video feeds locally without sending raw footage to the cloud.
* **Mathematical Vision Pipeline:** Instead of using computationally heavy object-detection neural networks (like YOLO), this system uses a highly optimized OpenCV pipeline. It converts frames to grayscale, applies Gaussian Blur, utilizes Adaptive Thresholding, and calculates non-zero pixel density within predefined spatial bounding boxes to determine occupancy.
* **Stateful Memory & Dwell Tracking:** The engine tracks the independent state of **543 individual parking spots**. It maintains a temporal memory of each spot to flag overstay violations (e.g., vehicles parked longer than the allowed duration).
* **Telemetry Streaming:** Live results are instantly serialized into a local SQLite database (`parking_data.db`) and a stateful JSON file (`spot_states.json`) for the frontend to consume.

### 2. The Intelligence Dashboard (`app.py`)
A modern, dark-mode web application built with Streamlit that acts as the command center for parking operators.
* **Interactive Digital Twin:** Reads the JSON telemetry to render a live, 2D Plotly scatter plot mapping the exact physical layout of the parking lot. Red indicates occupied/violating; Green indicates available.
* **Predictive Machine Learning:** Integrates Meta's **Facebook Prophet** algorithm to analyze historical SQLite data and forecast future parking availability, helping operators predict peak capacity hours.
* **Unsupervised Anomaly Detection:** Utilizes an **Isolation Forest** model to monitor the telemetry stream for sudden, unusual spikes or drops in parking volume, triggering automated security alerts.

## 📂 Repository Structure

* `step1_extract.py` - Extracts initial raw frames from drone footage for mapping.
* `step2_picker.py` - GUI tool for administrators to manually map and draw ROIs.
* `step3b_main.py` - Core computer vision pipeline and backend telemetry engine.
* `train_ai_engines.py` - Script used to pre-train the Prophet and Isolation Forest models.
* `app.py` - Streamlit frontend web dashboard.
* `CarParkPos.pkl` - Serialized coordinate geometry for the 543 spatial bounding boxes.
* `advanced_ai_models.pkl` - Pre-trained Machine Learning models (Prophet/Isolation Forest).
* `parking_data.db` - SQLite database containing time-series telemetry data.
* `spot_states.json` - Serialized spatial states for rendering the Digital Twin map.
* `live_frame.jpg` - Static image placeholder for cloud-deployed Computer Vision feed.
* `requirements.txt` - Production package dependencies.

## 🚀 Installation & Local Execution

Because this is a microservices architecture, you must run the backend engine and the frontend dashboard simultaneously in two separate terminals.

### 1. Clone & Install Dependencies
    git clone https://github.com/prahlad200/Advanced-Parking-Intelligence.git
    cd Advanced-Parking-Intelligence
    pip install -r requirements.txt

### 2. Start the Edge Vision Backend (Terminal 1)
This initializes the OpenCV video processing, begins frame analysis, and pipes live data to the SQLite/JSON files. (Requires parking_test.mp4 locally).
    python step3b_main.py

### 3. Start the Web Dashboard (Terminal 2)
This launches the frontend UI to visualize the live telemetry being generated by Terminal 1.
    streamlit run app.py

## ☁️ Cloud Deployment Notes

This application is configured for deployment on Streamlit Community Cloud. 
Because cloud deployment separates the frontend UI from the local video processing backend, the repository includes pre-populated parking_data.db, spot_states.json, and live_frame.jpg files. This ensures the cloud dashboard has historical data to render the Digital Twin and Machine Learning analytics for demonstration and portfolio purposes.
